# Security Policy

## Supported Versions

Only the latest release receives security fixes.

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Please report vulnerabilities privately through
[GitHub Private Vulnerability Reporting](https://github.com/fxkraus/checkmk-special-agent-aws-scim-token/security/advisories/new).
Do not open a public issue for security problems.

Include the affected version, the Checkmk version, and steps to reproduce.
Never include real AWS credentials, account IDs or event data in a report;
redact them first.

You can expect an initial response within 7 days. If the report is
confirmed, a fix is released as soon as possible and credited in the
release notes unless you prefer to stay anonymous.
